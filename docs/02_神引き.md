# 02. 神引きブースト

`BoostControls.tsx` に格納された、**プロンプトに即効性のある4種の修飾子＋風レベル**。

## ブースト4種

| ID | アイコン | 名前 | 効果 |
|---|---|---|---|
| `chaos` | 🎲 | 神引きカオス | 既出ジャンルから明示的に外し、未開拓モードを優先 |
| `world` | 🌍 | 別世界 | 通常モード（写実）から逸脱した世界観へ寄せる |
| `viral` | 🔥 | バズ寄せ | ZOZOトレンド age20 風 + 派手モチーフ強調 |
| `face` | ✨ | 顔映え | カメラ寄り・ライト盛り・髪/メイクの細部強調 |

**複数同時 ON 可能**。サーバの `boostBlock(req)` で対応するプロンプト断片が注入される。

## 風レベル（0-5）

`windLevel` は別枠で 0-5 段階のスライダー。

| Lv | 効果 |
|---|---|
| 0 | 風の言及なし（無風） |
| 1 | わずかなそよ風（毛先・布裾が少しなびく） |
| 2-3 | 中程度（髪流れ・スカートのしわ） |
| 4-5 | 強風（毛束が大きく流れる、布がはためく） |

**スコープゲート**: `windBlock` は `hair / outfit / foreground / pose / camera` のいずれかが選ばれているときだけ注入される（背景単独や視線変更で意味が薄い軸では無視）。

## 実装

### フロント
**ファイル**: `src/components/BoostControls.tsx`

- 4ボタン + 風スライダー（同じカード内、右寄せ）
- 状態は `App.tsx` の `activeBoosts: string[]` と `windLevel: number`
- localStorage 永続化（`settingsPersist.ts` の `PersistedSettings`）

### バックエンド
**ファイル**: `server/src/promptSystem.ts`

- `boostBlock(req)` が `req.boosts: string[]` を見て該当ブロックを返す
- `windBlock(req)` が scope-gated で風指示を返す
- どちらも ChatGPT 版と Nano Banana 版で文量を調整

### 型
**ファイル**: `server/src/types.ts`, `src/types.ts`

```ts
interface GenerateRequest {
  boosts?: string[];          // ["chaos", "world", "viral", "face"]
  windLevel?: number;         // 0..5
  // ...
}
```

## 注意

- 神引きは **生成プロンプト** にのみ影響する。実画像生成 API は呼ばない。
- AI判定が誤発火しやすいので、`face` ブーストは「写真用語」寄り（macro lens, rim light）にして自然な日本語/英語にしている。
- ブーストOFFのときはブロック自体を注入しない（プロンプトが無闇に長くならないように）。
