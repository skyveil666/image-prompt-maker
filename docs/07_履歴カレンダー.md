# 07. 履歴カレンダー

`CalendarView.tsx` — 月単位で生成数を可視化し、過去の任意の日にジャンプできるパネル。

## ファイル

| ファイル | 役割 |
|---|---|
| `src/components/CalendarView.tsx` | カレンダー UI |
| `src/components/HistoryView.tsx` | 日別の履歴一覧（カレンダーから受け取る） |
| `src/lib/history.ts` | 履歴 CRUD（IndexedDB） |
| `src/lib/historyAnalyzer.ts` | 集計（日別カウント、windowed 分析） |

- 各セルは「日付＋その日の生成数」
- 数値の大小は **色濃度** で表現（emerald 系のヒートマップ）
- クリックで HistoryView がその日でフィルタされる

## 集計ロジック

```ts
// 月の各日をループして historyItems から集計
function countByDay(items: HistoryItem[], year: number, month: number): Map<number, number>
```

- 日付は `new Date(item.createdAt).getDate()` で取得
- タイムゾーンはローカル
- 月の境界外（前月末・翌月頭）はグレーアウト

## ナビゲーション

- `<<` `>>` で月送り
- 「今日」ボタンで現在の月にジャンプ
- 日セルクリックで右ペインに該当日のリストを展開

## 既存機能との連携

| ボタン | 動作 |
|---|---|
| 日付をクリック | HistoryView を該当日でフィルタ |
| カードの ⭐ | お気に入り登録（06章へ） |
| カードの 🔄 | 同じプロンプトで再生成 |
| カードの 🎭 | アレンジ（部分置換） |

## デザインルール

- ヒートマップは emerald 系（落ち着いた緑）。激しい色は使わない
- 「今日」のセルだけ violet の枠でハイライト
- 数値はセル右下に小さく表示（0 のときは非表示）

## 永続化

- 履歴本体は IndexedDB `prompt-history` ストア
- カレンダーの「表示中の月」は localStorage に保存しない（毎回現在月起点）

## バグ修正履歴

- 月末日が次月にずれる問題（タイムゾーン）→ `getDate()` 統一で解決
- 生成直後にカレンダーが更新されない問題 → `historyVersion` ref で再レンダ強制

## 限界

- 1年以上前のデータは表示できるが、IndexedDB の容量制限（ブラウザごとに数百MB）に注意
- サムネイル付きで表示する場合は別ストア `image-thumbs` を参照
