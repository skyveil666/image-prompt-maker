# 06. お気に入り学習

⭐ を付けたカードからユーザーの好み傾向を抽出し、次回の生成に自動で寄せる機能。

## ファイル

| ファイル | 役割 |
|---|---|
| `src/lib/favoriteProfile.ts` | trait 辞書 + プロファイル合成 |
| `src/lib/idb.ts` | お気に入りの IndexedDB 永続化 |
| `src/components/FavoritesPanel.tsx` | 右ペインの一覧 / ⭐ 解除 |
| `src/components/FavoriteButton.tsx` | 各カードの ⭐ ボタン |
| `server/src/promptSystem.ts` | `favoriteProfileBlock(traits, strength)` の合成 |

## Trait 辞書（42 種）

`FAVORITE_TRAITS` に登録された ID 化された特徴。カテゴリは：

| カテゴリ | 例 |
|---|---|
| 髪 | `hair_long_silver`, `hair_bangs_blunt`, `hair_mesh_streak` |
| 衣装 | `outfit_pvc_leather`, `outfit_belt_straps`, `outfit_crop_lowrise`, `outfit_wa_dark` |
| 背景 | `bg_neon_alley`, `bg_ruins_graffiti`, `bg_wet_reflect` |
| エフェクト | `fx_rim_neon`, `fx_lens_flare`, `fx_motion_blur` |
| 表情 | `expr_cool`, `expr_smile`, `expr_serious` |
| カメラ | `camera_low_angle`, `camera_dutch` |
| その他 | small props, color schemes |

各 trait は **「タイトル」「英語キーフレーズ」「日本語フレーズ」「カテゴリ」「該当する出力モード」** を持つ。

## プロファイル合成

`buildFavoriteProfile(favorites)`:

```ts
return {
  favoriteCount: number;          // 全 ⭐ 数
  categories: { id, count }[];    // 多い順
  traitPhrases: { ja, en }[];     // プロンプト注入用
  topMoodLabels: string[];        // モード偏り
  viralRatio: number;             // バズ寄せ系の比率
};
```

頻出 trait（カウント ≥ 2）だけが採用される（外れ値で寄りすぎない）。

## 学習強度（0-5）

UI の「お気に入り学習」スライダー：

| Strength | 効果 |
|---|---|
| 0 | OFF（傾向は分析しても反映しない） |
| 1 | 微弱（参考程度） |
| 2-3 | 中（バランス重視） |
| 4-5 | 強（明示的に traits を強調） |

サーバ側 `favoriteProfileBlock(traits, strength)` が `strength` で文章量を切り替える。

## サーバブロック例

```
【ユーザーの好み（参考）】
過去の⭐から、以下の傾向が見られます。可能ならこの方向に寄せてください。
- 髪: 銀髪ロング / メッシュ流し
- 衣装: PVC レザー / クロップ＋ローライズ
- 背景: 廃墟 + グラフィティ / 濡れた路面
- エフェクト: ネオン リムライト
strength: 3
```

```
お気に入り学習  [○OFF][○弱][●中][○強][○最強]

```

## 永続化

| キー | 場所 |
|---|---|
| お気に入り本体 | IndexedDB `favorites` ストア |
| 学習ON/OFF | localStorage `ipm_settings_v1.favoriteLearnEnabled` |
| 強度 | localStorage `ipm_settings_v1.favoriteStrength` |

## 注意

- ⭐ の解除も即座に反映（IDBから削除→次回生成時から traits 落ちる）
- 強度0でも分析自体は走る（UIで傾向を見るため）
- traits は **既存スコープと衝突しない順序** で並ぶ（衣装→髪→背景→エフェクト）
- LLM 呼び出しなし、純粋なヒューリスティック集計
