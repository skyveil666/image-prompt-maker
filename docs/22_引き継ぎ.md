## 0. プロダクト概要

画像編集AI（**ChatGPT Image / Gemini / Nano Banana**）向けの **編集プロンプト生成＋履歴分析** Web アプリ。
1枚の元画像から「変更したい範囲だけ」を差し替えるプロンプトを複数案生成。顔・同一性維持を最優先。

- フロント: Vite6 / React18 / TS5 / Tailwind3（`localhost:5173`）
- サーバ: Express / Gemini 2.5 Flash（`localhost:3001`）※APIキーは `server/.env` のみ
- 永続化: **localStorage（設定）＋ IndexedDB（履歴・お気に入り・画像特徴）**
- 起動: `起動.bat`（フロント5173＋API3001）／ 開発単体は `npm run dev`

### 規模（2026-06-05）
- `src/App.tsx` ≈ **3039行**（巨大・Phase5で分割予定）
- components 51 / lib 48 / docs 22本
- useState≈88 / useMemo17 / useEffect23 / useCallback52 / useRef16

## 4. 履歴・お気に入り問題の調査結果

### 結論：**アプリのコードは履歴・お気に入りを消していない**
- `indexedDB.deleteDatabase` / `localStorage.clear` / `store.clear` の呼び出しは**コードに存在しない**（`idb.clear` は定義のみ・未使用）
- DB version（5）・objectStore 名・破壊的 migration は**いずれも未変更**
- 自動削除は `runAutoCleanup` のみ＝**90日超の「非お気に入り・非good・非protected」履歴だけ**。お気に入りは保護され消えない

### 実際の原因（切り分け）
- ユーザーは **`localhost:4330`（検証用 preview ポート）** を見ており 0件だった。
- IndexedDB は **オリジン（ポート）ごとに分離**。実データは通常使う **`localhost:5173`** にある。
- 5173 は **サーバー未起動（ERR_CONNECTION_REFUSED）** だっただけ＝データ消失ではない。`npm run dev` で 5173 を起動済み。
- → **ユーザーが 5173 を開いて復旧パネルの件数を確認すれば確定**（無事の可能性が高い）。
- 詳細: [21_recovery-panel.md](./21_recovery-panel.md)

## 6. 重要な設計方針（最重要原則 P1〜P7）

[master-plan-v1.md §2](./master-plan-v1.md) より。すべての改修はこれに照らす。

| # | 原則 |
|---|---|
| **P1** | 顔・同一性維持 **最優先** |
| **P2** | 変更対象だけ変更（scopes 列挙軸のみ） |
| **P3** | 背景固定ONなら背景変更禁止 |
| **P4** | 衣装OFFなら衣装変更禁止 |
| **P5** | 保護対象最優先 |
| **P6** | 反映ボタンを押した時だけ適用（ランタイム原則） |
| **P7** | 学習結果は自動適用しない（設計時禁則・自動適用経路を作るな） |

補助原則:
- **多層防御**: Layer1 buildInputs（不要軸を送らない）→ Layer2 promptSystem（厳守ルール）→ Layer3 Identity Shield＋Scope Filter（機械削除）
- **顔・同一性は faceLock 単一管理**（`LockKey` に face/identity/expression は無い）
- **APIキーはサーバ `.env` のみ**・安全基準回避の実装はしない
- **レイアウト制約**: ボタンサイズ/余白/配置/テーマカラー/構造は変更禁止（文字サイズ・色・ウェイトのみ可）。新規追加要素はOK

## 7. 触ってはいけない箇所（変更時は要・明示承認）

| 対象 | 理由 |
|---|---|
| `server/src/scopeFilter.ts`（`applyIdentityShield` / `applyServerScopeFilter`） | 顔・同一性保護の中核。採点・削除規則は不変厳守 |
| `server/src/promptSystem.ts`（プロンプト合成） | 出力プロンプト本文が変わる。文面・ブロック構造は触らない |
| `server/src/gemini.ts` | Gemini 呼び出し・応答処理 |
| `lib/preferenceProfile.ts` / `skyveilProfile.ts` / `skyveilScore.ts` / `favoriteProfile.ts` / `ratingAnalyzer.ts` | skyveil 学習・分析スコア計算 |
| `lib/colorAnalyzer.ts` / `historyAnalyzer.ts` / `imageAnalyzer.ts` / `biasAnalyzer.ts` | 分析スコア（変更すると結果が変わる） |
| `lib/cleanup.ts`（RETENTION_DAYS／除外条件） | **お気に入り・保護の無期限保持を壊さない**。90日を短縮しない |
| `lib/idb.ts`（DB_VERSION/store名/upgrade） | **migration破壊禁止・version変更は慎重に**。`clear`/`deleteDatabase` 禁止 |
| `lib/backup.ts` の import | **追加マージのみ。無断上書き・削除禁止** |
| `lib/history.ts`（getAll/saveBatch/deleteItem） | 履歴の単一データ源 |

### 絶対禁止
`indexedDB.deleteDatabase()` / `localStorage.clear()` / `store.clear()` / お気に入り自動削除 / お気に入りフラグ消失 / インポート時の無断上書き / 破壊的 migration / App.tsx の大規模分割を無計画に行う
