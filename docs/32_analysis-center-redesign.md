# 32. 分析センター 全面再設計（重複分析センター昇格・司令塔化）設計（承認済み 2026-06-07）

> 目的: 分析センターを「IPMの分析司令塔」へ。重複分析/AI分析/色分析/画像分析/評価集計＋頻出要素/頻出構成/🔭発見/未開拓度を、
>       全画面の独立画面で「何が多い/偏ってる/次に何を試す」が一目で分かる形に。
> 重要: 生成・保存・重複分析・評価・発見・Compare の各ロジック/データは**一切変更しない**（同 state/ハンドラ再利用・UI/UX再配置＋表示強化のみ）。

## 0. ユーザー決定（2026-06-07）
- **重複分析センター(DuplicateAnalysisPanel)を分析センター本体へ昇格**。小さい折りたたみインラインは**廃止**。
- 表示: **全画面モーダル 95vw×92vh**・Esc/✕で閉じる・閉じたら元画面復帰。
- 左メニュー: Explorer / カレンダー・履歴 / お気に入り一覧 / **分析センター**。
- ラボ統合: **完全統合・1画面**（頻出要素/頻出構成/🔭発見・件数/検索/ソートをセンターのタブへ統合、別ラボは廃止）。
- 進め方: **段階**（各段階で tsc/build/Playwright＋スクショ）。

## 1. 現状（調査済み）
- `DuplicateAnalysisPanel`（1946行）: インライン折りたたみカード（modalではない）。`expanded` state、✕=`onDismiss`。タブ `dup/agent/color/image/pref`（5）。サブ26個。全タブのデータ配線済み。件数/検索/ソートは無し（`.slice(N)` のみ）。`onOpenLab` で別ラボを開く。
- `AnalysisLabPanel`（全画面モーダル）: 頻出要素(未開拓度/🔭未開拓ビュー)/頻出構成/🔭発見（件数10/20/50/100/全件・検索・ソート・一括・無視）。
- 左メニュー `ImageSidebar`（UI1で「📊分析センター」ボタン追加済み）。

## 2. 段階計画
- **A1（土台・今回）**: DuplicateAnalysisPanel を全画面モーダル化（95vw×92vh・Esc/✕・backdrop・復帰）。左メニュー「分析センター」→ 起動。インライン廃止。`expanded` 常時展開・収納トグル撤去。5タブは全画面で広く。※ラボ統合(A1b)・各タブ強化(A2+)は後段。
- **A1b（ラボ統合）**: AnalysisLabPanel を embedded 化（外枠/自前タブを外し本体のみ）し、センターのタブ「頻出要素/頻出構成/🔭発見」として統合。別ラボ起動は廃止（左メニューは1本化）。
- **A2 重複分析強化**: 件数 20/30/50/100/全件＋頻出構成/頻出要素/重複カテゴリ/別ジャンル候補/NG候補/許可候補。
- **A3 AI分析**: 問題点/原因/おすすめ/次の行動 の4ブロック＋色分け（赤危険/黄注意/青提案/緑おすすめ）。
- **A4 色分析/画像分析**: 色分析を全画面前提で大型化（衣装色/髪色/背景色/ライティング色/差し色）。画像分析を背景/衣装/髪型/カメラ/ライティングのカード化。
- **A5 評価集計**: 期間別 7/30/90/全期間＋背景/衣装/髪型/カメラ/ライティング/空気感/色味 の評価推移。
- **A6 共通**: 検索/ソート/カテゴリフィルタの統一。理解しやすさ優先の情報設計。

## 3. 不変条件・検証
- 不変: 重複分析/評価/発見/Compare/生成/保存ロジック・levels/comboPolicies/colorWeights/motifTags/ignoredTerms。
- 検証（各段階）: tsc -b / vite build / Playwright隔離（左メニューから開く・95vw×92vh・Esc/✕・タブ・件数/検索/ソート・各操作・既存データ不変）＋スクショ。

**残（段階）**: A1b ラボ統合（頻出要素/頻出構成/🔭発見タブ・件数/検索/ソート・別ラボ廃止）→ A2 重複強化 → A3 AI4ブロック → A4 色/画像 → A5 評価集計 → A6 共通。

## 4.2 A1b 設計（次段階・ユーザー指定 2026-06-07）
**前提**: A1 を実機で数日評価（サイズ/タブ配置/スクロール量/閉じる導線/左メニュー配置）。問題なければ A1b へ。

**A1b でやること（完全統合・1画面）**
- 分析センターのタブに **頻出要素 / 頻出構成 / 🔭発見** を統合（現 AnalysisLabPanel の本体を embedded 化して取り込み、別ラボ起動は廃止）。
- 統合タブ（頻出要素/頻出構成）に **件数セレクタ 20/30/50/100/全件**（TOP5 では不足）。検索・カテゴリ/タグフィルタ・ソート（出現/未開拓度/直近/名前/レベル）。一括操作（NG/制限/許可/タグ/無視）。
- 🔭発見は P3a の候補抽出（定型除外層込み）をそのまま統合。
- 重複分析タブ内の頻出構成プレビュー（A1で上位5件）も、統合後は件数セレクタ対応へ。
- 実装方式: AnalysisLabPanel に `embedded`/`embeddedTab` を追加し外枠・自前タブを抑制 → 分析センターの統合タブバーから本体のみ描画。App から lab 用 props（motifCounts/topCombos/candidates/onIgnoreTerm 等）をセンター経由で供給。
- 不変条件: 検出/生成/抽出/保存・既存 levels/comboPolicies/motifTags/ignoredTerms は不変（再配置のみ）。

**A2 以降**: 重複カテゴリ/別ジャンル候補/NG候補/許可候補ビュー（A2）、AI 4ブロック色分け（A3）、色/画像カード化（A4）、評価集計 期間別＋軸別推移（A5）、共通検索/ソート/フィルタ統一（A6）。
