# 04. 重複分析センター

`DuplicateAnalysisPanel.tsx` — **過去の生成傾向を可視化＋制御** するためのパネル。
タブ切替で「重複制御」と「AI分析」を持つ。

## タブ構成

```
[ 重複制御 ] [ AI分析 ]
```

## タブ1：重複制御

### モチーフレベル（0-5段階）

`src/lib/motifPolicy.ts`

```ts
type MotifLevel = 0|1|2|3|4|5;
DEFAULT_LEVEL = 4;
```

| Lv | 意味 | UI色 |
|---|---|---|
| 0 | 一発NG（完全禁止） | rose |
| 1 | 強く抑制 | amber |
| 2 | 抑制 | yellow |
| 3 | 普通 | slate |
| 4 | 既定（出やすい） | sky |
| 5 | 強く促進 | violet |

各モチーフ（`MONITORED_MOTIFS` の ~20 種）に対して 0-5 のセグメントを表示。
0 を選ぶと「🚫 一発NG」扱いで `getNgTokens()` に追加され、サーバの NG リストに渡る。

### 頻出構成 TOP10

`historyAnalyzer.ts` の `detectTopCombos(history, motifIds, windowSize)` が、
直近 N 件から **2要素・3要素の同時出現** を検出。subset-dedup で大きい組合せを優先。

```
1位 🔴 [ドレス][花][夕焼け] × 48 回
   [🚫 今後出さない] [🎭 別ジャンル化] [許可]
2位 🟠 [金髪][制服] × 31 回
   ...
```

各組合せに `ComboPolicy` を設定：

| Policy | 効果 |
|---|---|
| `block` | プロンプトの NG リストに入れて完全排除 |
| `alt` | 別ジャンル化（同じ要素をベースに別系統へ寄せる） |
| `allow` | 既定（何もしない） |

### 自動調整

「✨ 重複を自動調整」ボタン：
`computeAutoAdjust(current, input, preserveManual)` が、
偏りが強いモチーフのレベルを下げ、未開拓モチーフのレベルを上げる。

- 「全上書き」モード: 手動設定を無視
- 「保護モード」（既定）: 手動で変えたレベルは触らない
- 「↶ 元に戻す」: 直前の状態に戻す（`levelsUndoStack`）

変更されたモチーフは ring highlight で `changedIds` 表示。

### フッタ

```
要素：制御 N件 / 完全NG N件 ・ 構成：禁止 N件 / 別ジャンル化 N件
```

## タブ2：AI分析

`src/lib/aiAgent.ts` の `analyzeAgent(input)` 出力を表示。
出力は `AgentAnalysis`：

```ts
{
  trendSummary: string;
  problems: { severity: "high"|"medium"|"low", text: string }[];
  recommendations: string[];
  actions: AgentAction[];   // 6種類のアクション
}
```

### 6 アクション

| ID | 表示 | 効果 |
|---|---|---|
| `apply` | ✨ 反映 | 提案されたレベル変更を一括適用 |
| `see_alternative` | 🎭 別案 | 別ジャンル化トグルを ON |
| `avoid_overlap` | 🔁 回避 | 重複モチーフを抑制レベルへ |
| `favorite_bias` | ⭐ 好み | お気に入り学習を強める |
| `simplify` | 🧹 シンプル | 神引き / 補助系を解除 |
| `go_bold` | ⚡ 攻める | カオス + バズ寄せ ON |

これらは `App.tsx` の `handleAgentAction(id)` 経由で対応する setter を呼ぶ。
**アシスタントキャラの提案ボタンも同じ ID** を使う（再利用）。

## サーバ連携

### 送信ペイロード

```ts
{
  motifControls: [{label, level}, ...],   // Lv1-5 の制御リスト
  ngList: ["金髪", ...],                   // Lv0 = 一発NG をマージ
  comboControls: [
    { labels: ["ドレス","花","夕焼け"], policy: "block" },
    ...
  ],
}
```

### サーバ側ブロック

`server/src/promptSystem.ts`：

- `motifControlBlock(req, pt)` — Lv1〜5の指示を pt 別に整形
- `comboControlBlock(req, pt)` — 構成単位の禁止 / 別ジャンル化指示

`pt === "nano_safe"` なら短く、`chatgpt_safe` なら詳細に。

## 状態とキー

```ts
// localStorage
"ipm_motif_levels_v1"     → LevelMap
"ipm_combo_policies_v1"   → ComboPolicyMap
```

`policyApplied` フラグで「適用中かどうか」を保存、UI のヘッダに反映。
