## 長期（3ヶ月以上 / アイデア段階）

### マルチユーザー / プロジェクト
- 👥 **プロジェクト切替**：仕事用 / 趣味用などで履歴・お気に入りを分離
- ☁ **クラウド同期**：IndexedDB を Firebase / Supabase に同期
- 🔗 **共有 URL**：プロンプト＋画像をリンクで共有（パスワード保護）

### AI 強化
- 🧠 **LLM ベース別ジャンル化**：現状はヒューリスティック → Gemini で文脈考慮した提案
- 🎨 **ビジョンモデル統合**：⭐画像から構図 / カメラアングル / ライティングを自動抽出
- 💬 **AI分析エージェントの LLM 化**：ヒューリスティック → Gemini Function Calling

### カレンダー機能拡張
- 📌 **「今日のおすすめ」自動投稿**：日替わりで未開拓ジャンルを1つ提案
- 🏆 **マイルストーン**：100枚 / 1000枚 / 1年継続などの達成バッジ
- 📤 **エクスポート**：月別 PDF レポート

### 出力先の追加
- 🎨 **Midjourney V7 形式**：`--ar 9:16 --style raw` などの記法に変換
- 🎬 **Sora 形式**：動画用プロンプト（時系列指示付き）
- 🖼 **Stable Diffusion XL**：positive / negative / LoRA タグの構造化

## 既知の課題（要修正）

- [ ] サムネイルキャッシュが肥大化して IndexedDB クォータに当たる → 古いものから LRU 削除
- [ ] CalendarView の月切替が一瞬カクつく → useMemo 化
- [ ] 大量履歴時（1万件超）の `historyAnalyzer` が遅い → Web Worker 化
- [ ] Nano Banana 出力の英語混在比率が安定しない → ターゲットとなる単語リストを増やす

---

## やらないこと（明示的に範囲外）

- ❌ **画像生成 API の追加**：本アプリは「プロンプト生成」専用。実画像は外部 AI で。
- ❌ **安全基準回避の実装**：危険表現を別表現で隠す機能は作らない。
- ❌ **API キーのブラウザ側保存**：必ずサーバの `.env` のみ。
- ❌ **UI レイアウトの大規模変更**：ボタンサイズ・余白・配置・テーマカラーは固定。
