# 00. 概要

## 目的

画像編集AI向けに「コピペで使える高品質なプロンプトを大量に作る」ためのワークベンチ。
1枚の元画像から、変更したい範囲だけを差し替えた **ChatGPT Image / Nano Banana** 用プロンプトを並列に出力する。

## コアコンセプト

1. **2系統同時出力** — 同じ意図を2つの記法に翻訳して並べる
   - ChatGPT Image: 日本語・項目分け・長め・安全前提文付き
   - Nano Banana: 短文命令型・英語混在OK・face-lock 最優先

2. **スコープ駆動** — 「変更したい範囲」を選ぶと、その軸だけが変化する
   - 背景 / ポーズ / 髪 / 衣装 / 表情 / 小道具 / 視線 / カメラ
   - 選んでない軸は完全ロック（顔・体型・同一性は常時ロック可能）

3. **履歴フィードバック** — 過去 N 回の生成内容を集計してプロンプトに反映
   - 偏り検知 → 自動回避
   - 頻出構成 → 別ジャンル化
   - 神引き → 既出ジャンルから明示的に外す

4. **AI分析エージェント** — 重複分析センター内の「AI分析」タブで「次の一手」を提案
   - 勝手に設定変更はしない（提案ボタンを押した時のみ反映）

## アーキテクチャ

```
[Browser]                            [Express server]
 ┌────────────────┐                   ┌────────────────┐
 │ React + Vite   │ ──── POST ───────▶│ /api/generate  │
 │                │                   │                │
 │ - UI/UX        │                   │ - Validation   │
 │ - localStorage │                   │ - Prompt build │ ──▶ Gemini 2.5 Flash
 │ - IndexedDB    │ ◀──── JSON ───────│ - Variety eng. │
 └────────────────┘                   └────────────────┘
                                            │
                                            └─ server/.env (API key)
```

- **API キーはサーバの `.env` だけに存在**。ブラウザは API キーを知らない。
- フロントは UI / 履歴管理 / 設定 / 分析 を担当。
- サーバはバリデーション + プロンプト合成 + Gemini 呼び出しに専念。

## データ層

| 種別 | 保存先 | キー例 |
|---|---|---|
| アプリ設定 | localStorage | `ipm_settings_v1`, `ipm_motif_levels_v1`, `ipm_combo_policies_v1`, `ipm_assistant_settings_v1` |
| 履歴 | IndexedDB | `prompt-history` データベース |
| お気に入り | IndexedDB | `favorites` ストア |
| サムネイル | IndexedDB | `image-thumbs` ストア |
| 認証情報 | サーバの `.env` のみ | `GEMINI_API_KEY` |

## 安全方針

- 安全基準を**回避する目的の実装はしない**
- 危険な内容を別表現で隠さない
- 純粋に「安全で誤判定されにくい自然な日本語」へ整える方向で対応
- 実在人物モードでは「架空キャラ」前提文は出さない（誤適用防止）
