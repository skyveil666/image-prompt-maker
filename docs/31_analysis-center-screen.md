# 31. 分析センター 独立画面化（UI/UX再編）設計（承認済み 2026-06-07）

> 目的: 重複分析センターがインラインで窮屈（TOP10が限界・操作ボタンが詰まる）。290要素・発見タブ・未開拓度・重複構成を扱うため**独立画面**化する。
> 重要: 生成・保存・分析ロジック、既存の NG/別ジャンル化/許可/タグ/無視データは**一切変更しない**（同じ state/ハンドラを再利用＝UI/UX再配置のみ）。

## 0. ユーザー決定（2026-06-07）
- スコープ: **バランス統合**＝分析センターに 重複分析(概要)/頻出要素(未開拓度含)/頻出構成/🔭発見/評価集計。色分析・画像分析・AI分析エージェントは当面インライン据え置き。
- 進め方: **段階**（UI1→UI2）。
- 表示方式: **全画面モーダル**（既存 AnalysisLabPanel＝92vh全幅前面ビューを流用。Escで閉じる）。

## 1. 現状（調査済み）
- `AnalysisLabPanel`＝全画面モーダル（件数10/20/50/100/全件・検索・カテゴリ/タグ・ソート・一括レベル/ポリシー・タグ・🔭発見/無視）。タブ＝頻出要素(未開拓度列・🔭未開拓ビュー)/頻出構成/🔭発見。`setAnalysisLabOpen(true)` で起動。
- `DuplicateAnalysisPanel`＝メイン内インライン（折りたたみ）。タブ＝重複分析/AI分析エージェント/色分析/画像分析/評価集計＋AIコメント＋TOP10構成＋「分析ラボを開く」。
- 左メニュー＝`ImageSidebar`（カレンダー/履歴＝view切替、お気に入り一覧＝モーダル）。`onShowCalendar`/`onShowFavorites` と同様に `onShowAnalysis` を足せる。
- 起動機構 `setAnalysisLabOpen` は既存。同じ state/ハンドラ（levels/comboPolicies/motifTags/ignoredTerms 等）を再利用するためデータ不変。

## 2. UI1（今回）
1. `ImageSidebar`: お気に入り一覧の下に「**📊 分析センター**」ボタン（`onShowAnalysis`）。App で `setAnalysisLabOpen(true)` に配線。
2. `AnalysisLabPanel`: ヘッダ表記を「🔬 分析ラボ」→「**📊 分析センター**」に改称（機能不変）。
3. `DuplicateAnalysisPanel`: 「分析ラボを開く」→「**📊 分析センターを開く**」に改称＋上部で目立たせる。インラインの **TOP構成プレビューを上位数件に縮小**＋「全件・操作は分析センターで」CTA（重い全件操作は分析センター頻出構成タブへ）。
4. 操作ボタンの横幅整理（分析センターは全幅なので、頻出要素/頻出構成の操作行に余白を確保）。
- 件数 10/20/50/100/全件 は頻出要素/頻出構成/発見で既に動作。

## 3. UI2（次回）
- 分析センターに **評価集計**タブ（`ratingAnalysis` 再利用）＋ **重複分析(概要)**タブ（AIコメント/重複度/新規性/次回推奨・読み取り）を追加。件数/検索/ソートを各タブへ。
- インラインの 評価集計 も概要化。
- 「昇格候補」操作は P3b 実装後に有効化（UI枠のみ先行も可）。

## 4. 不変条件・検証
- 不変: 生成/保存/抽出/分析ロジック・既存 levels/comboPolicies/motifTags/ignoredTerms・色/画像分析は変更しない。再配置と表記のみ。
- 検証（各段階）: tsc -b / vite build / Playwright隔離＝左メニューから分析センターを開ける・10/20/50/100/全件切替・検索・ソート・各操作ボタン押下・既存データ（levels/tags/ignored）が消えない。
