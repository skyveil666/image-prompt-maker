# 03. AIアシスタントキャラ

Explorer 左下に常駐するキャラ。
過去の生成傾向を分析した `AgentAnalysis` を **短文化・口調変換・感情付与** して吹き出しで提示し、ワンクリックで反映できる。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/components/AssistantCharacter.tsx` | UI 本体（アバター / 吹き出し / ボタン / 設定モーダル） |
| `src/lib/assistantSettings.ts` | localStorage 永続化（既定値 / Tone 一覧） |
| `src/lib/assistantEngine.ts` | AgentAnalysis → 短文＋感情＋アクションに変換 |
| `src/lib/assistantSpeech.ts` | Web Speech API ラッパー |
| `src/lib/aiAgent.ts` | 分析エンジン本体（ヒューリスティック） |

## UI 構成

```
┌─[avatar]── ナビ ⚠️ ── 🔊 ⚙ ▼ ─┐
│ ┌──────────────────────────┐ │
│ │ ドレス全般が448回出ています…  │ │  ← 吹き出し（感情カラー枠）
│ └──────────────────────────┘ │
│  [✨反映] [🎭別案] [🔁回避]      │  ← 最大3つの提案ボタン
│  [🔥攻めたい][🧹シンプル][⭐好み] │  ← 気分切替
└──────────────────────────────┘
```

折りたたみ時はアバターのみ（クリックで復元）。

## 感情（6種）

`assistantEngine.ts` の `EMOTION_META`:

| Emotion | アイコン | リング色 | 用途 |
|---|---|---|---|
| `normal` | 🙂 | slate | 既定 |
| `idea` | ✨ | violet | 推奨あり |
| `warn` | ⚠️ | amber | 高/中 severity 問題 |
| `bold` | 🔥 | rose | 攻める提案 |
| `tired` | 😴 | sky | データ不足 |
| `celebrate` | 🎉 | emerald | 問題なし |

優先順位：高severity → warn ／ 中severity → warn ／ 推奨 → idea ／ それ以外 → celebrate

## 口調（6種）

`AssistantTone`：

| Value | 例 |
|---|---|
| `default` | 「ドレス全般が448回出ています。」 |
| `gentle` | 「ドレス全般が448回出ていますね。」 |
| `energetic` | 「ドレス全般が448回出ています！」 |
| `harsh` | 「ドレス全般が448回。多すぎ。」 |
| `cool` | 「ドレス全般448回。推奨：別ジャンル化。」 |
| `short` | 「ドレス全般が448回出ています。」（36字でカット） |

`applyTone()` 内の正規表現で語尾を変換。LLM 呼び出しなしの軽量実装。

## 気分切替（hint）

ユーザがチップを押すと `speak()` の hint 引数に `bold | simplify | favorite` を渡す：

- `bold`: 「🔥 攻めるなら、神引きカオス＋バズ寄せで意外性を狙う構成にしてみる？」
- `simplify`: 「🧹 変更範囲を絞ってシンプルに。神引きと補助は一旦解除しよう。」
- `favorite`: 「⭐ お気に入り傾向ONで好みの方向に寄せた案を作るよ。」

それぞれ対応する action ボタンが出る（押すまでは何も変わらない）。

## アバターのフォールバック

`<Avatar />` 内部状態 `stage` で3段階：

```
"user"    → settings.avatarUrl (data URL) を表示
   ↓ onError
"default" → /assistant-default.png を表示
   ↓ onError
"svg"     → コード内 SVG プレースホルダ
```

## 音声読み上げ

### 仕様

- ブラウザ標準 `window.speechSynthesis` のみ使用（追加依存ゼロ）
- 非対応ブラウザでは🔊ボタンを非表示
- 新しい発話で前のものを即キャンセル（被らない）
- 絵文字・記号は読み上げ前に自動除去

### 設定項目（`AssistantSettings`）

| キー | 型 | 既定 | 説明 |
|---|---|---|---|
| `speechOn` | boolean | true | 機能ON/OFF |
| `autoSpeak` | boolean | false | 発話変化で自動再生 |
| `voiceURI` | string\|null | null | 使用ボイス。null=自動選択 |
| `rate` | number | 1.05 | 速度（0.5〜2.0） |
| `pitch` | number | 1.10 | ピッチ（0.5〜2.0） |

### 動作

```ts
// 自動読み上げ：sp.text が変わった瞬間に1回だけ
useEffect(() => {
  if (!settings.autoSpeak) return;
  if (sp.text === lastSpokenRef.current) return;
  lastSpokenRef.current = sp.text;
  speakText(sp.text, { voiceURI, rate, pitch });
}, [sp.text, ...]);
```

unmount で `cancelSpeech()`。

## 重要ルール

- **勝手に設定変更しない**：提案ボタンは押下時のみ `handleAgentAction()` を呼ぶ
- **画面を占領しない**：左下の固定スロット、折りたたみで縮小可能
- **短く要約**：吹き出しは1〜2文、口調 `short` なら36文字まで
- **アクションは既存ハンドラに委譲**：6種のアクション ID は AI分析タブと完全に共有
