## 主要パネル

### MiniExplorer（左ペイン）
**ファイル**: `src/components/MiniExplorer.tsx`

- フォルダツリー（仮想）
- 画像サムネイルグリッド（IndexedDB から復元）
- 検索 / フィルタ / ホバーアクション
- ステータスバー（"N 枚" 表示）

### メインプロンプト編集エリア
中央ペインの上から順に：

| コンポーネント | 役割 |
|---|---|
| `ImageUploader` | D&D / クリック / Ctrl+V でアップロード |
| `ScopeSelector` | 変更範囲（背景/ポーズ/髪/衣装/表情/小道具/視線/カメラ） |
| `MoodSelector` | 雰囲気プリセット |
| `LockToggles` / `FaceLockSwitch` | 顔・体型・同一性の常時ロック |
| `DetailsCard` | 詳細設定アコーディオン（初期は閉じ） |
| `NgInput` | 任意 NG ワード |
| `ExtraInstructions` | 任意の追加指示 |
| `ZozoTrendBar` | 年代別トレンド（05章） |
| `BoostControls` | 神引き4種 + 風（02章） |
| `DuplicateAnalysisPanel` | 重複分析センター（04章） |
| `PromptTargetSelector` | ChatGPT / Nano Banana 切替（既定は両方） |
| `CountSelector` | 生成案数（2/3/4/5/6） |
| 生成ボタン | サーバ呼び出し |
| `PromptCard` × N | 出力。ChatGPT版・Nano Banana版を**並列**に表示 |

### 右ペイン
**ファイル**: `src/components/HistoryView.tsx`, `CalendarView.tsx`, `FavoritesPanel.tsx`

- 履歴一覧（タブ切替）
- カレンダー（07章）
- お気に入りパネル（⭐から再生成）

## デザイントークン

- ダークテーマ既定
- アクセント色：violet 系（神引き・お気に入り）
- 警告：amber / rose
- 成功：emerald
- 中立：slate

## レイアウト制約（厳守）

- **変更可**: 文字サイズ / 色 / ウェイト / placeholder色
- **変更禁止**: ボタンサイズ / カードサイズ / 余白 / 配置 / レイアウト / 枠線 / テーマカラー / コンポーネント構造

## 状態管理

中央集権ではなく **App.tsx に集約された useState** + 各 lib への純粋関数委譲。
永続化は `settingsPersist.ts` がまとめて localStorage に書き戻す。

```
[App.tsx] ─┬─ levels         (motifPolicy.ts)
           ├─ comboPolicies  (motifPolicy.ts)
           ├─ activeBoosts   (settingsPersist)
           ├─ zozoApplied    (settingsPersist)
           ├─ windLevel      (settingsPersist)
           ├─ favoriteStr    (settingsPersist)
           └─ agentAnalysis  (aiAgent.ts, useMemo)
                  ▼
           [DuplicateAnalysisPanel: AI分析タブ]
```
